# ABOGADO ACTIVO RD ⚖️
### MEJI v1.0 - Motor de Expedientes Jurídicos Inteligentes

Plataforma para abogados en RD. Carga un caso real, diagnostica la acción legal y genera los escritos automáticamente.

**Stack:** Github + Vercel + Next.js

---

### 🚀 CÓMO USAR

1.  **Diagnóstico Legal**  
    Describe los hechos → El sistema sugiere: Art 109 CPC + Ley 5869 + Jurisprudencia aplicable

2.  **Generador de Escritos**  
    1 Click para generar: Demanda, Ampliatorio, Poder, Querella, Depósito de Documentos

3.  **Base de Jurisprudencia**  
    10+ Sentencias SCJ y TC etiquetadas por tema: Desalojo, Propiedad, Ley 5869

4.  **Gestión de Casos**  
    Agenda, pruebas, testigos y seguimiento de audiencias
